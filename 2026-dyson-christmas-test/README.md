# Dyson 聖誕活動 v85｜測試站完整包

包內包含網站程式、圖片、字型、音樂、影片與 Apps Script 原始碼。

## 更新測試站

1. 若測試站尚未使用支援簽到 5 天的 v85 Apps Script，請用本包的 `GS/DysonProgress.gs` 更新測試用 Web App 並部署新版。若測試站與正式站目前使用同一個 `/exec` 網址，請另建測試專用部署，保留正式站的原部署版本。
2. 解壓縮後，把整個 `2026-dyson-christmas-test/` 資料夾上傳至 GitHub 儲存庫原本的測試站位置。確認 `index.html` 直接位於該目錄下，避免多一層同名目錄。若測試站使用新的 `/exec` 網址，先在本包的 `assets/js/config.js` 填入測試用網址再上傳。
3. 等 GitHub Actions 中的 `pages-build-deployment` 成功後，開啟測試頁並確認頂端顯示 v85。

`GS/DysonProgress.gs` 用於 Apps Script 編輯器。上傳 GitHub 時使用 `2026-dyson-christmas-test/` 裡的檔案。

## 這版包含

- 簽到 5 天。桌機護照夾好禮位於水晶球操作按鈕下方，手機位於「每日解鎖」上方。
- 「活動與好禮」中的「01 活動辦法」和「注意事項」收合列同高，分隔線貼齊收合區底部。優惠券區顯示護照夾圖片和兌換說明。
- 行銷意願勾選框下方有「個人資料告知暨同意書」連結。
- 商品券維持日期與卡片任務條件。測試站使用獨立測試進度，優惠券與護照夾資格僅供預覽。
