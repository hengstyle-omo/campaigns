## 後續填入網址

只要打開assets/js/config.js最上方的DYSON_COUPON_LINKS，把引號內的空字串換成完整HTTPS網址即可：

```js
window.DYSON_COUPON_LINKS = {
  "product-hd19": "",
  "product-sv50": "",
  "product-hj10": "",
  "product-bp10": "https://bmai.app/0566ddd3",
  "visits-10": ""
};
```

product-bp10是既有的任一主機券識別，請保留這個鍵名；visits-10是護照夾兌換券。網址不必放進Google Sheet，也不必重部署GS。填入後更新測試版網頁並重新整理；必要時更新index.html的config.js查詢版本，避免讀到舊快取。

網址留空不會導向首頁或其他商品，也不會用測試序號替代。正式領券平台的內容與使用條件仍以實際券面為準。
