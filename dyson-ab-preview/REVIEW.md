# 架構 Review、Legacy 清理與素材更新 · v59

## 結論

v55 清理階段只以你上傳的 `2026-dyson-christmas.zip`（內部版本 v54）為修改來源，沒有合併其他歷史 ZIP。現行靜態前端、Apps Script 與私有 Sheet 的分工可以繼續沿用。前端的主要問題是舊載圖流程仍耦合啟動、大量失去引用的資產，以及設定檔混入產圖資料；這三項已完成清理。

| 設定檔職責 | `config.js` 同時包含活動設定、現用素材及不會執行的舊產圖資料，品牌描繪座標又佔大量縮排空間。 | 移除 `artDirection`、圖集欄位與 `sourceDay`；保留星光秀真正使用的字形資料並緊縮其序列化。檔案由 148,912 降至 47,578 bytes。 |
| 素材一致性 | 檔名可能保留舊名稱，單看檔名不能確定圖像內容；曾出現程式更新而圖檔未換的問題。 | 新增 48 個現用媒體的 SHA-256 清單及 `scripts/check-assets.mjs`，可攔截缺圖、誤換舊圖與未登記檔。 |
| 主程式集中 | `app.js` 同時處理遊戲、狀態、雲端同步、Canvas、卡片與錄音，後續擴充容易互相影響。 | 本次保留模組介面與業務邏輯。下一次功能開發時，適合依「雲端狀態／場景／卡片」漸進拆分。 |
| CSS 累積覆寫 | 樣式有多輪補充與相同選擇器覆寫，畫面仍依賴最後生效的規則。 | CSS 逐位元組保留，避免在素材清理時改變版型；可另以視覺回歸測試整理。 |
| 字型體積 | 兩個中文字型合計 8,649,704 bytes（約 8.6 MB）。 | 保留完整字集，維持任意中文卡片留言的顯示；字型切分需另做功能驗證。 |
