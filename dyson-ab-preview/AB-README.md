# A/B 圖片比較

此包以 v59 程式為基礎，加入獨立的圖片比較入口。先附上對照表 A「原版北歐紋理」及 B「簡潔色塊插畫」各 18 個物件，包含橘貓聖誕老公公。

## 開啟

將此資料夾放到網站後，開啟 `compare.html`，或在活動網址後加上 `?artCompare=1`。直接開啟一般 `index.html` 仍是活動模式。

切換 A／B 時，水晶球、下方瀏覽圖與物件詳情圖會同步更新。球內選擇、座標及縮放不會改變。首次切換需載入圖片，再次切換會使用記憶體快取。

比較頁預設展示八件物件；可按「放入全部造景」或「清空球內造景」，再從下方選入想比較的物件。原有「調整位置」可繼續使用。

## 換成自己的版本

- A：`assets/images/scene/a/`
- B：`assets/images/scene/b/`

直接覆蓋上述資料夾內的同名透明 WebP，檔名不加 vxxx。每個版本都有相同 18 個檔名，列於 `AB-ASSET-MANIFEST.json`。

修改顯示名稱或資料夾位置：編輯 `assets/js/art-compare.js` 中的 `versions`。每次換圖後，更新同檔的 `revision` 值以更新瀏覽器快取；不需要修改圖片檔名。

比較頁只將本次擺放保存在記憶體，不讀寫正式收藏、IndexedDB 圖片及 Google Sheet，也不送出 GA 事件。重新整理會恢復八件示範。網址保留所選 A／B。四款產品、動態特效及額外動物繼續使用原素材。

這是獨立預覽包，尚未上傳到 GitHub 或套用為正式活動樣式。此包原始活動資料來自 v59；後續自行修改過的活動程式，請先保留自己的最新版本。
