# v45：專屬收藏與管理者權限分開

以已交付的 v44 為更新基準，只需差異包；既有圖片、音樂、字型與樣式沿用。

## 部署步驟

1. 從原 Google Sheet 開啟「擴充功能 → Apps Script」，用包內 `apps-script/DysonProgress.gs` 完整取代舊程式並儲存。不要同時保留重複的舊函式；若自行加入過允許網域，請保留 `ALLOWED_ORIGINS` 設定。
2. **先部署新版程式**：「部署 → 管理部署作業 → 原部署的鉛筆 → 版本選新版本 → 部署」。原身分、所有人可存取等設定沿用，原 `/exec` 網址不變。
3. 函式選 `setupV9`，按「執行」。它會先備份，再新增權限欄並整理順序，不用手動插欄。原 `setupV7()`、`setupV8()` 也會轉呼叫這次新版設定。
4. 將本包 `2026-dyson-christmas/` 下檔案合併覆蓋 GitHub 的同名活動資料夾並推送，保留差異包未包含的檔案。
5. 等 GitHub Pages 完成部署後，重新整理活動頁，再以目標 Email 載入進度。新版前端資源標記為 `20261024-permissions-v45`。

本次共七個檔案：`index.html`、`assets/js/app.js`、`assets/js/config.js`、`apps-script/DysonProgress.gs`、`README.md`、`VERSION.txt`、本部署說明。`.gs` 放 GitHub 只保存來源，仍需執行步驟 1–3。

## Sheet 權限怎麼勾

更新後前四欄：

**A Email → B 是否管理者 → C 是否有專屬收藏 → D 同意行銷**

| B 是否管理者 | C 是否有專屬收藏 | 可使用功能 |
| --- | --- | --- |
| 不勾 | 不勾 | 一般活動與聖誕卡片 |
| 勾選 | 不勾 | 一般活動＋日期模擬／管理畫面 |
| 不勾 | 勾選 | 一般活動＋全部十款限定動物，無法模擬 |
| 勾選 | 勾選 | 一般活動＋日期模擬／管理畫面＋全部十款限定動物 |

新欄位預設 FALSE、不勾選。**原管理者如也要看動物，請另外勾選 C 欄。** 兩種權限獨立；不會因為勾選其中一個而自動勾另一個。

給特定人權限時，請先讓對方用 Email 保存一次，在 `Participants_2026` 找到該 Email 的資料列，勾選「是否有專屬收藏」。對方重新整理頁面、等進度同步後，即會看到「你的限定收藏」。不要新增只有 Email 而缺少系統 Email_Key 的空白資料列代替活動存檔。

同意行銷仍為獨立選填欄，與管理／收藏權限無關。

有參加者資料時，第一次設定會建立並隱藏 `Participants_2026_backup_v45_時間` 備份，名稱存於 `DYSON_V45_BACKUP` 指令碼屬性；舊 v44 備份也保留。重跑設定不會清除既有權限及進度，但會再套用上述預設欄位順序。

## 專屬收藏保存與取消

- 專屬帳號的動物可自由放入／移除及移動，保存於該 Email 的正式擺設；重新整理或使用相同 Email 可接續。
- 專屬收藏不讓使用者領取未來的每日禮物、不增加正式收藏數、不直接開啟優惠券，也不提供管理介面。
- 取消專屬收藏，下一次讀取進度會隱藏動物並停止接受動物擺設變更；原位置資料保留，重新勾選可恢復。
- 取消管理者資格，下一次讀取會退出正在使用的模擬；如果專屬收藏仍勾選，正式場景的動物仍可使用。
- 兩個都勾選時，正式與模擬的動物擺設分開保存。

網頁介面與後端都檢查各自權限。依原先確認，本活動仍以未驗證的 Email 作為識別，不增加驗證碼或登入程序。
