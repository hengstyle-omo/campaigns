# v47 更新方式

基準為已上傳的 v46，只需覆蓋本差異包的檔案，保留原有素材與其他檔案。

1. 將 `2026-dyson-christmas/` 內檔案依原路徑合併至 GitHub 的 `campaigns/2026-dyson-christmas/`，提交並推送。不要先刪除整個活動資料夾。

4. 開啟 dyson 氣流後，細雪揚起、積雪速度約為原本的 3.6 倍；從零開始約 2 分半到上限。關閉氣流恢復一般速度。移除第一場雪仍保留白色薄雪底。
