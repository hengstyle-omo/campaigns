## 如何更新

1. 將新版 `DysonProgress.gs` 貼回原本 Google Sheet 的 Apps Script 專案，儲存。本次未新增欄位，已完成建置者不需清空 Sheet 或重跑 setup。
2. 到「部署 → 管理部署作業 → 鉛筆 → 版本：新版本 → 部署」。編輯原部署，沿用相同 `/exec` 網址與權限。
3. 更新網站：將 ZIP 解壓到本機的 campaigns 儲存庫根目錄，以包內同名檔案覆蓋，再 Commit、Push。小型更新包要合併檔案，請保留既有圖片、音樂與字型。
4. 等 GitHub Pages 部署完成，按 Command＋Shift＋R，輸入相同 Email 載入進度。勾選行銷意願後，應看見「行銷意願已保存至 Google Sheet」。
5. 若回覆「不支援此操作」或沒有保存確認，表示 Apps Script 正式部署仍是舊版；只有儲存程式不會更新 `/exec`，請完成第 2 步。

只修改 GitHub，沒有更新 Apps Script 部署，行銷勾選即時同步不會生效。其他原有收藏、模擬、動物權限與物件位置均沿用原紀錄。

### 如何給指定 Email 解鎖

1. 更新 Apps Script 並執行 `setup`，Sheet 會新增私人分頁 **`Bonus_Access_2026`**；既有進度不會清除。
2. 第一列為 `Email` 及十種動物名稱。第二列預設是管理帳號，十欄均為 `TRUE`。
3. 每位收件人新增一列，第一欄填 Email，想給的動物填 `TRUE`，其他填 `FALSE` 或留白。可以選一隻、多隻或全部。這些欄位也可自行設為 Google Sheet 核取方塊。
4. 例如只給海獺：第一欄填對方 Email，`海獺` 欄填 `TRUE`，其他動物欄填 `FALSE`。不要更動表頭文字或欄位順序；皇帝企鵝幼鳥仍沿用 `企鵝` 欄；白色小海獅沿用原 `海豹` 欄（動物第 7 欄），無須改表頭或重新部署 Apps Script。
5. 參加者重新載入相同 Email 後，就會看到指定的收藏。每次改名單不需重傳 GitHub 或重新部署 Apps Script；第一次升級程式仍需重新部署原有部署。
6. 取消權限改成 `FALSE`，對方下次載入進度會隱藏該動物；原擺設仍留在資料中，再給權限可還原。正在開啟的畫面不會即時推送更新。

Email 不驗證，沿用此輕量活動的識別方式。未指定 Email 的人看不到限定收藏區。

- 每個模擬活動日期只記一次測試簽到；直接選 12/10 只增加一個日期，不會自動補滿 10 次簽到。可依序切換不同日期測試第五份禮遇。
- 往前模擬時，只顯示當日及之前的收藏與簽到；已保存的後續測試紀錄不會刪除。
- 模擬收藏、擺放、位置、日期與測試簽到同步至 `Preview_2026`，與正式紀錄分開；換瀏覽器輸入相同 Email 可接續。
- 舊版多日勾選會自動轉為單日模擬，以原先的模擬日期為準，保留收藏及位置。既有 Sheet 欄位保留，不需改表頭。
- 結束模擬會保存測試紀錄；內容管理中的「清空測試進度」清除測試收藏及測試簽到。
- Email 未驗證；指定 Email 是此輕量活動的識別與測試入口限制，不是信箱持有人驗證。

## 保存與行銷意願

- Email 用於保存、找回進度，不需要密碼或驗證碼，也不寄確認信。
- 首次參加時行銷勾選預設不勾選，不同意也能參加。填 Email、按保存後開始同步；已連接 Email 者勾選或取消就立即保存，需配合第 6 版 Apps Script。
- 新瀏覽器填相同 Email 會先讀取既有意願，未動過的預設空白勾選框不會覆蓋已保存的同意。
- 自動保存時顯示「進度保存中」，失敗則顯示「進度待同步」。可開啟我的進度重試；尚未送出的編輯保存在同一瀏覽器。
- 在兩個裝置切換前先等同步完成。不同日期的修改會合併；同一物件同時編輯時以後送達的修改為準。

## 第一次建置

1. 建立私人 Google Sheet，由「擴充功能 → Apps Script」貼入 `DysonProgress.gs`。
2. `ALLOWED_ORIGINS` 填 GitHub Pages 網域 `https://hengstyle-omo.github.io`，不含 `/campaigns/` 或活動路徑。
3. 執行 `setup` 並授權。程式會自動建立三個分頁。
4. 部署成網頁應用程式，執行身分選「我」，存取權選「所有人」，將 `/exec` 網址填入 config.js 的 `DYSON_CLOUD_CONFIG.endpoint`。
5. 完整網站 ZIP 解壓後取得 `2026-dyson-christmas`，整個資料夾上傳至 `campaigns` 儲存庫根目錄。
6. GitHub Settings → Pages 選 Deploy from a branch、main、/(root)，沿用既有設定即可。

`DysonProgress.gs` 貼在 Sheet 的 Apps Script，另行下載；GitHub 不執行 `.gs`，網站 ZIP 裡不包含它。
