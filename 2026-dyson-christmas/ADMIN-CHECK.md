# 新增管理者後未顯示日期模擬

從提供截圖可見「是否管理者」已勾選；前端程式不以「同意行銷」作為管理條件，無須為模擬日期而勾選行銷。

目前前端僅在進度服務連線成功、後端回傳isAdmin為布林true，以及canPreview為布林true時，顯示日期模擬與管理入口。僅填Email或勾選前端欄位無法繞過後端權限。

先重新整理活動頁，使用新增管理者的完整Email重新保存／載入進度。正在開啟的頁面不會因Sheet勾選自動推送權限；目前返回頁面的自動重連也受活動日期限制，因此十月新增勾選後，應主動重新載入。

若仍未出現日期模擬，需檢查目前部署的Apps Script：
- 連到的試算表是否正是所修改的Participants_2026。
- 是否按正確Email列讀取「是否管理者」核取方塊。
- 回傳的isAdmin、canPreview是否均為布林true，而非字串TRUE。
- 若程式碼更新過，現用/exec部署是否仍執行舊版本。

本次能取得的獨立DysonProgress.gs為較舊版本，與現用前端要求的服務協定不同，不能用它認定線上問題或覆蓋現用後端。請提供目前Apps Script原始碼或檔案，才能定位並針對實際版本修正；不要用舊檔取代，也不需清空Sheet。
