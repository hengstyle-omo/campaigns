# v46 更新方式

基準為已上傳的 v45，只需上傳本差異包內檔案。

1. 將 `2026-dyson-christmas/` 內檔案依原路徑合併至 GitHub 的 `campaigns/2026-dyson-christmas/`，提交並推送。
2. 等 GitHub Pages 完成部署，再重新整理。資源版本標記為 `20261024-welcome-snow-v46`。
3. 從「活動介紹」開啟 popup，確認 Email 優先呈現。已看過介紹的裝置不會因這次更新而強制再次彈出。
4. 放入「第一場雪」，等待約 3–5 秒看地面變白，約 15 秒形成較高的小雪丘。只有收藏但未放入，不會開始積雪。
5. 可開啟 dyson 氣流觀察表面細雪；關閉動態時顯示靜態雪層。移除第一場雪會清空積雪，重新放入後再開始。

本包共七個檔案：`index.html`、`assets/css/style.css`、`assets/js/app.js`、`assets/js/config.js`、`README.md`、`VERSION.txt`、本說明。圖片、音樂、字型及後端程式沿用 v45。

**本次不需重新部署 Apps Script，也不用再執行 setupV9。** 若前版尚未完成後端更新，仍須依 v45 說明處理；本包不會修復仍部署舊 Apps Script 的服務。

優惠提示已簡化為「製作聖誕卡片即可領取」，實際機制仍為下載或成功分享一次卡片、填寫 Email 並同步後，領取已達成條件的優惠。只產生預覽或取消分享仍不算完成。

雪量為當次頁面的視覺效果，不增加參與天數、收藏數或優惠進度，不上傳 Sheet。正式與模擬模式分開；同一模擬模式切換日期保留雪量，重新整理頁面會重新開始。PNG 取當下雪境，GIF／MP4 使用共用積雪繪圖。

完成的驗證包含桌機／手機 Email 首屏可見、行銷選填預設不勾、簡短保存視窗、累積時間與上限、氣流不晃動水晶球、實際 PNG／GIF 輸出、既有進度及優惠流程。MP4 使用相同動畫繪圖，但錄音與影片編碼仍需在實際手機／電腦驗收。本次未直接修改你的正式 Sheet，也未替你上傳 GitHub。
